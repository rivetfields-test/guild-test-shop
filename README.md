# guild-demo-shop

EXAMPLE ONLY. This is not a real shop and has no customers. It exists to demonstrate Guild's review loop on a team-controlled repository: one Linear issue, one pull request, a review brief, a human revision request and an updated result.

Evidence from this repository is not customer validation.

## Run it

No dependencies. Serve the folder with any static server, for example `npx serve .`, then open the page.

## Check it

    npm test

## Checks

Run the tests with `npm test`.
